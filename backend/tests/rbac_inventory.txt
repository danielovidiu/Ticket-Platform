# One line per guarded route: the role class required to reach it. test_rbac.py derives
# the same table from the app at run time and asserts the two match exactly.
#
# WHY THIS FILE EXISTS. The derived table alone cannot catch a change to the access model,
# because the model IS what it derives. Widening a route from `require_admin` to
# `require_admin_or_editor` simply re-files it, and the "editors are refused here" test
# stops being generated for it — silently, with the suite still green. Verified: that
# mutation passed before this file existed.
#
# So the categorisation is pinned here instead. Any diff to this file is a deliberate
# change to who can reach what, and has to be made in the same commit as the code.
#
# Regenerate (and READ the diff — that is the point):
#   venv/bin/python -c "import sys;sys.path.insert(0,'tests');import test_rbac as t;\
#     print('\n'.join(f'{c:6} {m:6} {p}' for m,p,c in t.GUARDED))" >> tests/rbac_inventory.txt
#
